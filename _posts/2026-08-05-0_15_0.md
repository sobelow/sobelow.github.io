### [0.15.0](v0150)

* Enhancements
  * Added `--no-router` flag for scanning projects that have no Phoenix router (shorthand for `--router :none`, also settable in `.sobelow-conf`)
  * `.sobelow-skips` now written in sorted order for smaller diffs (`--legacy-skips` restores the old append-only behavior)
  * `# sobelow_skip` comments now supported on Phoenix router pipelines, not just functions
  * Unreadable `# sobelow_skip` comments now warn on stderr instead of being silently dropped
  * `--private` now skips the version check entirely, making no network requests or file writes
  * Documented `SOBELOW_HOME` as the directory holding the version-check cache
  * Added `usage-rules.md` for AI coding assistants (via the `usage_rules` convention) and `AGENTS.md` for contributors
  * Added support for Elixir v1.20.x
* Bug fixes
  * `Config.Secrets` no longer crashes the scan on heredoc or escaped-quote secret values
  * A corrupt or unreadable version-check cache file no longer aborts the scan
  * `--strict` now reports syntax errors instead of raising
  * An unparseable template is now skipped (or reported under `--strict`) instead of aborting the scan
  * A malformed `.sobelow-conf` now produces an actionable message instead of a raw stacktrace
  * An empty, whitespace-only, or comment-only `.sobelow-conf` is now read as no options instead of crashing
  * `--save-config` now stores `ignore_files` relative to the project root
  * `Config.Secrets` now reports the correct line for `config` calls that span multiple lines
  * An unwritable `~/.sobelow` no longer fails a scan
  * Fixed a string-interpolation typo affecting dot-access variable rendering
  * `.sobelow-conf` keys are now genuinely sorted alphabetically
  * `version`, `details`, `all-details`, `save-config`, and `diff` are no longer read from `.sobelow-conf`, so a stray committed file can no longer make a scan silently exit clean
  * `# sobelow_skip` comments are no longer dropped over spacing variations
  * `SQL.Query` no longer reports a project's own `query/1` as SQL injection unless Ecto is actually in scope
* Misc
  * Added an end-to-end test harness, taking line coverage from 29% to 67%
  * Replaced the deprecated `:preferred_cli_env` project key with `def cli`
  * Bumped `credo` to `~> 1.7.19`
  * Removed a dead Elixir 1.5 version guard and an always-true conditional in the SARIF renderer

**Upgrade notes**
  * `Config.Secrets` line numbers may shift for multi-line `config` calls, which can invalidate matching `.sobelow-skips` entries — re-run `mix sobelow --mark-skip-all` if affected
  * Secrets that previously crashed the scan (heredoc/escaped-quote values) will now surface as new findings
  * `SOBELOW_HOME` now points at a directory rather than the cache file path directly
